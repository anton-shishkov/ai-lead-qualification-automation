# 60–90 second screen recording plan

| Time | Screen | Suggested narration |
| --- | --- | --- |
| 0–12 s | Open `data/sample_leads.csv`; point to realistic roles, blanks, duplicates. | “Here is a raw B2B lead list with strong prospects, weak fits, missing fields, and duplicate contacts.” |
| 12–24 s | Show the full n8n canvas. | “The local n8n workflow triggers a repeatable qualification pipeline. Each stage is documented, from validation through final classification.” |
| 24–36 s | Click **Execute workflow** and show the final summary. | “In mock AI mode it runs without an API key, removes duplicate contacts, and writes a clean results file.” |
| 36–48 s | Open `data/qualified_leads.csv`; highlight score breakdown and status. | “Each lead receives an explainable baseline score, an AI assessment, a final score, and a Hot, Warm, or Cold priority.” |
| 48–64 s | Open dashboard and show KPI cards, ranked table, distribution charts. | “The dashboard summarizes the lead mix and ranks contacts so a sales team can focus its next actions.” |
| 64–78 s | Filter to **Hot**, select a lead, show outreach preview and download button. | “I can filter to Hot leads, review the qualification reason and personalized opening, then export the shortlist as CSV.” |

Rehearse the local n8n import and start both apps before recording. Keep the browser zoom wide enough to show the workflow and dashboard table clearly. All names and companies in this demo are fictional.
